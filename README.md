 Tools: [ React.js, Node.js, Express.js, MySQL, BeautifulSoup/Selenium (for Web Scraping)]

 
 ∗ Developed a full-stack web application that displays real-time IPO listings and company details.
 ∗ Implemented secure user authentication with a login/signup system using MySQL.
 ∗ Scraped IPO data from financial websites using BeautifulSoup/Selenium and stored it in a structured format.
 ∗ Built a dynamic UI using React.js to present IPO listings with real-time updates.
 ∗ Designed and developed RESTful APIs with Express.js to connect the frontend and backend.
 ∗ Ensured smooth data flow between the backend and frontend for a seamless user experience.
